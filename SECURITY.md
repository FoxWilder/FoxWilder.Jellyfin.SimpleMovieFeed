# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please do not disclose security vulnerabilities, credentials or authentication material in a public GitHub issue.

Use GitHub's private vulnerability reporting feature when it is available for this repository.

Include enough information to reproduce and understand the issue, but never include real Jellyfin tokens, qBittorrent API keys, passwords or other credentials.

## Credential handling

SimpleMovieFeed is designed so runtime authentication material can remain outside the Git repository.
